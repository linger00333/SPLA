# SPLA implementation

The `spla` package provides transforms, the online prior estimator, feature
alignment modules, and YOLOv11-RGBT training integration. `tools` contains
explicit command-line entry points for conversion, prior tuning, training,
video inference, and CPU scoring. See the repository documentation for the
tested scope and completed artifacts.
